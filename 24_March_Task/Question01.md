Question01 : What is an object in JavaScript?

Answer: 
In JavaScript, an object is a collection of related data and functions stored as key–value pairs.

🔹 Simple Definition

An object lets you store multiple values in a single variable, where each value has a name (called a key or property).

🔹 Example
let user = {
  name: "Karthika",
  age: 30,
  isStudent: false
};

Here:

name, age, isStudent → keys (properties)
"Karthika", 25, false → values
